# Уведомления

**rtr-subs** — неофициальное дополнение для Podkop 0.7.24. Оно не связано с проектом Podkop,
не одобрено его авторами и не является Podkop или его официальной версией.
Название Podkop здесь используется только для описания совместимости.

## Лицензия

Файлы в `files/` и `patch/` — изменённые версии файлов Podkop (GPL-2.0) и новые файлы,
распространяются на условиях GNU GPL версии 2 (см. `LICENSE`).
Изменения: поддержка подписок (`files/subscription.sh`, правки в `files/podkop`,
`files/section.js`, `files/main.js`). Полный список правок — `patch/podkop-subscription.patch`.

`files/podkop.ru.lmo` собран из `podkop.ru.po` Podkop утилитой `po2lmo` проекта LuCI (Apache-2.0).

## Сторонний компонент

Ядро sing-box ставится из проекта `podkop-net/podkop-engine` (неофициальная сборка sing-box).
Установщик скачивает его с GitHub и проверяет контрольную сумму. Это отдельный проект
со своей лицензией и своими авторами.

## Если вы публикуете это дополнение

Политика Podkop (`TRADEMARK.md`) запрещает использовать название Podkop и его вариации
в названии модифицированной версии. Не называйте репозиторий или пакет «podkop-что-то».
